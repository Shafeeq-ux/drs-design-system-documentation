Form control

The label block that sits next to a checkbox, radio button or switch: a label, an optional count and an optional description.

Figma base component.aec-control · .aec-form-label

Markup

<label class="aec-control">
  <input class="aec-checkbox" type="checkbox" name="plan">
  <span class="aec-form-label">
    <span class="aec-form-label__text">Protection plan <span class="aec-form-label__count">(3)</span></span>
    <span class="aec-form-label__desc">Covers parts and labour for 5 years</span>
  </span>
</label>

Modifiers: .aec-control--reverse puts the control after the label. .aec-control--between pushes the control to the far end of a full-width row.

Accessibility

Label in name WCAG 2.5.3

Because the input sits inside the <label>, the label text, count and description all become the control's accessible name. For long descriptions, move them out of the label and reference them with aria-describedby.

Figma notes

  • This is a hidden base component in Figma (.form control label).
  • In the small size, the count stays at 14px while the label drops to 12px. The code scales both.
  • Count is on by default in Figma, so instances show "(0)" unless it's turned off.
