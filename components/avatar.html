Avatar

Represents a person, such as the shopper, a co-applicant or a dealer contact, with initials, a user icon or a photo.

21 Figma variants.aec-avatar

An avatar is a small picture of a person. It helps people tell who is who, for example the main applicant and a co-applicant on a finance application, or which dealer contact sent a message. It shows initials, a user icon or a photo, in four colours (neutral, outline, primary, inverse) and three sizes. Avatars aren't interactive on their own. To make one open something, put it inside a button, as the header does.

Usage

  • Fall back to the user icon when no name is known, for example for a guest shopper.
  • Combine an avatar with a badge dot to show unread messages from a dealer.
  • Use one size for all avatars in a list or group.

Do / don't: usage

Content

Initials are the first letter of the first name and the first letter of the last name. The avatar shows them in capitals, so pass them in as they are. For a single name, use one letter. Don't add punctuation.

Accessibility

Text alternatives WCAG 1.1.1

When the person's name is shown next to the avatar, hide the avatar (aria-hidden="true", or alt="" on an image). When it appears alone, give it the name: alt="Dana Lee" or role="img" aria-label="Dana Lee".

Not a control WCAG 4.1.2

An avatar is a picture, not a button. If it opens a menu or a profile, wrap it in a <button> and name the button, for example aria-label="Account, Alex Morgan".

Don't rely on colour WCAG 1.4.1

Avatar colour alone must not carry meaning. Say roles and statuses in text.

Text contrast WCAG 1.4.3

Initials need at least 4.5:1 against the avatar background. These ratios are measured live from the avatars below in the active brand.

Figma notes

Differences found in the Figma library, for the design team to review:

  • Most variants use legacy, off-palette colours (#494dac indigo, #f1f1f3, #787987, #242529). The code maps them to tokens: primary → primary/default, emphasis neutral → bg/inverse, neutral → bg/variant with text/subtle.
  • Only the medium neutral-initial variant uses styles: an outlined ring, available here as --outline.
  • Initials weights vary (bold and semibold). The code takes the weight from the brand's avatar typography tokens, the same at every size.
