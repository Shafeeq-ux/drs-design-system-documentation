Usage

  • Use one or two initials, from the first and last name.
  • Fall back to the user icon when no name is known, for example for a guest shopper.
  • Combine an avatar with a badge dot to show unread messages from a dealer.

Accessibility

Text alternatives WCAG 1.1.1

When the person's name is shown next to the avatar, hide the avatar (aria-hidden="true", or alt="" on an image). When it appears alone, give it the name: alt="Dana Lee" or role="img" aria-label="Dana Lee".

Contrast WCAG 1.4.3

All token pairs meet AA: text/subtle on bg/variant is 5.13:1 and white on primary/default is 4.53:1.

Figma notes

  • Most variants use legacy, off-palette colours (#494dac indigo, #f1f1f3, #787987, #242529). The code maps them to tokens: primary → primary/default, emphasis neutral → bg/inverse, neutral → bg/variant with text/subtle.
  • Only the medium neutral-initial variant uses styles: an outlined ring, available here as --outline.
  • Initials weights vary (bold and semibold). The code uses demi throughout.
