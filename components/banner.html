Banner

A compact strip with an icon and a short, neutral message, shown across the top of a page or section.

2 Figma variants.aec-banner

A banner shares useful context that doesn't need a response, such as a delivery estimate or a current offer. Banners are neutral: they have no success, warning, error or info colours. When a message has a status, use an alert. To confirm an action someone just took, use a snackbar.

Variants

Banners have one style. The title is always shown; the description and close button are optional. Change the icon to suit the message.

Title only

A single fact, such as the vehicle's status.

This vehicle is in transit to your dealer.

Title and description

A fact plus one short detail. They sit on one line from 768px up and stack on mobile.

Estimated arrival: Nov 12

We'll email you when it's ready.

Dismissible

For promotions and other messages people can safely hide.

0% APR on select models.

The banner itself isn't interactive. Only the optional close button has states. Focus adds the 2px focus/default ring.

Usage

Content

  • Title: lead with the key fact, for example Estimated arrival: Nov 12. Write it in sentence case.
  • Description: optional. One short detail or the next thing that will happen. Use a full stop if it's a sentence.
  • Avoid attention-grabbing words such as "Important" or "Attention". If something is urgent, it isn't a banner.
  • Banners don't have an action. If people need to act, use an alert with a link, or put a button on the page.

Accessibility

Landmark WCAG 1.3.1

A site-wide banner can be wrapped in <aside aria-label="Announcement">. If it's added after the page loads, give it role="status".

Decorative icon WCAG 1.1.1

The icon repeats the message, so give it aria-hidden="true". The title must make sense without it.

Dismissing WCAG 2.1.1

The close button is a labelled icon button. When the banner is removed, move focus to the next element so keyboard users don't lose their place.

Contrast WCAG 1.4.3 · 1.4.11

Text needs at least 4.5:1 against the banner background, and the icon needs 3:1. These ratios are measured live in the active brand. The bar in the last row is a sample of the icon colour.

Figma notes

  • Banner has an 8px radius in Figma, while Alert and Tooltip are square and Snackbar is 4px. The brand token --drp-banner-container-bg-border-radius differs by brand and, for DRS Base, doesn't match the Figma value. Consider aligning these.
  • The border style is set but has a stroke weight of 0. The page also holds loose Avenir font-specimen layers.
  • The smaller mobile padding has no brand token. In code the vertical mobile padding is a fixed value, so it doesn't re-theme.
