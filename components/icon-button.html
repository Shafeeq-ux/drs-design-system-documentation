Icon button

A compact button that shows only an icon. Use it for common, recognisable actions such as close, edit, share or more options.

3 Figma component sets · 216 variants.aec-icon-btn

Variants

Primary

Blue. Use it for an action that relates to the main task.

Neutral

Dark grey. The default for utility actions such as close and more options.

Inverse

For dark surfaces.

Shape and size

Rectangle (8px radius) is the default. Circle (--circle) suits floating actions and image overlays.

Usage

Do
Use universally understood icons, and add a tooltip with the action name.
Don't
Don't use an icon button for a primary or unfamiliar action such as Apply for credit. Use a labelled button.

Accessibility

Accessible name WCAG 4.1.2 · 1.1.1

Every icon button needs aria-label, such as aria-label="Close". Mark the icon itself aria-hidden="true".

Target size WCAG 2.5.8

The small size (24px) meets the minimum, but on touch screens use 40px or 48px.

Toggles WCAG 4.1.2

For an on/off action such as Save vehicle, add aria-pressed and keep the same label.

Figma notes

  • The Figma default variant is medium / plain / rectangle, and the code uses the same defaults.
  • Neutral filled and outline go back to the default colour when pressed. The code keeps the hover colour.
  • Primary disabled outline and plain use #c3cfd9 for the icon, but Neutral uses icon/disabled (#b3b3b3).
