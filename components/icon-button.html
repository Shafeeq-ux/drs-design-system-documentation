Icon button

A compact button that shows only an icon. Use it for common, recognisable actions such as close, edit, share or more options.

3 Figma component sets · 216 variants.aec-icon-btn

An icon button does the same job as a button, but saves space by dropping the label. It comes in three emphasis colours (primary, neutral, inverse), three styles (plain, filled, outline), three sizes and two shapes. Because there is no visible label, only use it for actions people already recognise, and always give it an accessible name.

Variants

Plain is the default style. Use filled or outline when the button needs to stand out from busy content, such as a vehicle image.

Primary

Uses the brand's primary colour. Use it for an action that relates to the main task.

Neutral

Uses the neutral ink colour. The default for utility actions such as close and more options.

Inverse

For dark surfaces such as the header, hero banners and image overlays.

Rectangle is the default shape. Add .aec-icon-btn--circle for floating actions and image overlays, such as gallery arrows.

States

Every emphasis and style has default, hover, focus, pressed and disabled states. The colours come from the same tokens as the text button (--drp-button-contained-color-<emphasis>-<style>-<state>-*), so switch the brand in the header to see how each one changes. Focus adds a 2px focus/default ring, 2px outside the button.

Usage

Accessibility

Accessible name WCAG 4.1.2 · 1.1.1

Every icon button needs aria-label, such as aria-label="Close". Mark the icon itself aria-hidden="true". Make the name specific when there are several on a page, for example aria-label="Remove trade-in".

Target size WCAG 2.5.8

The small size ( in this brand) meets the 24×24px minimum only if it has space around it. On touch screens use medium or large.

Toggles WCAG 4.1.2

For an on/off action such as Save vehicle, add aria-pressed and keep the same label. Swap the icon (for example save to saved) so the state is visible too.

Keyboard WCAG 2.1.1

Use a real <button type="button">. It is reached with Tab and activated with Enter or Space, with no extra script.

Focus visible WCAG 2.4.7

Every icon button shows a 2px focus/default ring on :focus-visible. Don't remove it.

Icon contrast WCAG 1.4.11

The icon is the only thing that tells people what the button does, so it needs at least 3:1 against its background. These ratios are measured live from the buttons below in the active brand. Disabled buttons are exempt.

Figma notes

  • The Figma default variant is medium / plain / rectangle, and the code uses the same defaults.
  • Neutral filled and outline go back to the default colour when pressed. The code keeps the hover colour.
  • Primary disabled outline and plain use #c3cfd9 for the icon, but Neutral uses icon/disabled (#b3b3b3).
