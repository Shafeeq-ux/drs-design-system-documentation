Pagination Beta

Splits long lists, such as inventory search results, across pages and lets people move between them.

Legacy Figma component, remapped.aec-pagination

The Figma Pagination uses an older colour palette and older variables. The styles below map it to the current tokens and are pending design review.

Pagination shows how many pages of results there are and which one people are on. It has numbered page links, previous and next arrows, an ellipsis for skipped pages and an optional page-size select. There's also a compact text version for small screens. Pagination has no brand tokens of its own: it uses the semantic --aec-color-* and --drp-typography-body-* styles (through the site aliases), so it follows each brand's base colours and fonts.

States

Page items have default, hover, current and disabled states. Hover tints the background with bg/variant and darkens the text. The current page has a action/border/active border and bold primary/default text, as in the example above. Disabled items, such as the previous arrow on page 1, use text/disabled.

Hover and keyboard focus can't be forced for pagination yet, so try them on the live example above. Focus adds a 2px focus/default ring.

Usage

  • Use pagination when people need to find their place again, such as inventory results. For feeds, consider a Show more button.
  • Place pagination below the list, centred or aligned with the content.
  • Keep filters and sorting when people change pages, and scroll back to the top of the list.

Content

  • Label the arrows "Previous page" and "Next page" with aria-label. In the text version, use "Previous" and "Next".
  • Write the position as Page 2 of 12 and the results count as Showing 21–40 of 236 vehicles.
  • Write page-size options as 20 / page, with a hidden label "Results per page".

Accessibility

Landmark and current page WCAG 1.3.1 · 4.1.2

Use <nav aria-label>, mark the current page with aria-current="page", and label the arrow links ("Previous page").

Target size WCAG 2.5.8

Default items are tall, with between them, which meets the 24×24px minimum. Small items are , so don't use them on touch screens.

Keyboard WCAG 2.1.1

Every page item is a link, so Tab moves through them and Enter follows them. Disabled arrows have no href and aria-disabled="true", so they're skipped.

Focus after changing page WCAG 2.4.3

If the list updates without a page load, move focus to the results heading and announce the new page, so screen reader users know it changed.

Text contrast WCAG 1.4.3

Page numbers need at least 4.5:1 against the page. These ratios are measured live in the active brand. Disabled items are exempt.
