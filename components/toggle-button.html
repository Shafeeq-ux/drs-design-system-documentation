Toggle button

A button that stays pressed, or a segmented group of them for choosing one option from a small set, such as a loan term or vehicle trim.

Figma Option 1.aec-toggle · .aec-toggle-group

Figma has three competing explorations (Options 1–3). This site implements Option 1, the newest set and the only one with icons on by default. See the Figma notes.

Toggle button

An outlined button that fills with the primary colour when it is on. Use it for an independent on/off filter, such as Electric only.

Toggle button group

A segmented control for picking exactly one option. By default the items share a 500px maximum width equally. Add .aec-toggle-group--hug so items size to their content.

States

Toggle buttons and group items have default, hover, focus, pressed and disabled states, both when off and when on. The colours come from the brand's toggle tokens (--drp-toggle-button-color-option-1-* and --aec-toggle-group-tab-item-color-option-1-*), so switch the brand in the header to see how each one changes. Focus adds a 2px focus/default ring, 2px outside the button.

Group spacing

Items in a group sit apart (--aec-spacing-selectable-gap-m). Separate toggle buttons used as filters should use the same gap.

Usage

Content

Keep labels to one or two words, in sentence case, and about the same length. Use the same unit for every option.

Accessibility

Toggle state WCAG 4.1.2

Single toggles use aria-pressed. Groups use role="radiogroup" with role="radio" and aria-checked, plus an aria-label on the group.

Keyboard WCAG 2.1.1

A single toggle is reached with Tab and switched with Enter or Space. In a group, Tab moves to the selected item, and the arrow keys and Home/End change the selection (components.js).

Not colour alone WCAG 1.4.1

A selected group item gets a thicker border as well as the colour change. A toggle that is on is filled, not just recoloured.

Keep the label WCAG 4.1.2

Don't change a toggle's label when it switches on. The pressed state already tells screen reader users that it is on.

Focus visible WCAG 2.4.7

Toggles and group items show a 2px focus/default ring on :focus-visible. Don't remove it.

Text contrast WCAG 1.4.3

Labels need at least 4.5:1 against their background. These ratios are measured live in the active brand. Disabled items are exempt.

Figma notes

  • The Toggle Button, tab item and group each exist in three options. Decide which one ships, then remove the others.
  • In Option 2, selected and unselected look the same. In Option 3, disabled doesn't grey out the label.
  • The tab-item masters are 24px tall but stretch to 40 or 48px inside groups.
  • The code adds a 1px inner shadow to selected group items so they stand out more.
