Toggle button

A button that stays pressed, or a segmented group of them for choosing one option from a small set, such as a loan term or vehicle trim.

Figma Option 1.aec-toggle · .aec-toggle-group

Figma has three competing explorations (Options 1–3). This site implements Option 1, the newest set and the only one with icons on by default. See the Figma notes.

Toggle button

A blue outline that fills when pressed. Use it for an independent on/off filter, such as Electric only.

Toggle button group

A segmented control for picking exactly one option. By default the items share a 500px maximum width equally. Add .aec-toggle-group--hug so items size to their content.

Usage

  • Use a group for two to five short, mutually exclusive options that people compare side by side. For more options, use a select or radio buttons.
  • Keep labels to one or two words, all about the same length.
  • A group always has one option selected. Don't use it for actions.

Accessibility

Toggle state WCAG 4.1.2

Single toggles use aria-pressed. Groups use role="radiogroup" with role="radio" and aria-checked, plus an aria-label on the group.

Keyboard WCAG 2.1.1

In a group, Tab moves to the selected item, and the arrow keys and Home/End change the selection (components.js).

Not colour alone WCAG 1.4.1

A selected group item gets a thicker border and darker text as well as the colour change.

Figma notes

  • The Toggle Button, tab item and group each exist in three options. Decide which one ships, then remove the others.
  • In Option 2, selected and unselected look the same. In Option 3, disabled doesn't grey out the label.
  • The tab-item masters are 24px tall but stretch to 40 or 48px inside groups.
  • The code adds a 1px inner shadow to selected group items so they stand out more.
