Snackbar

Briefly confirms the result of an action, such as Vehicle saved, with a message that disappears on its own.

4 Figma variants.aec-snackbar · AEC.snackbar()

A snackbar appears at the bottom of the screen after someone does something, then goes away. It never blocks the page. Snackbars are neutral: they have no success, warning, error or info colours. When something goes wrong or needs a decision, use an alert. For context that isn't a response to an action, use a banner.

Try it

// JavaScript API (components.js)
AEC.snackbar({
  message: 'Vehicle saved to your garage',
  action: 'View',
  onAction: () => location.assign('/garage'),
  variant: 'inverse', // optional
  timeout: 6000 // ms, default 6000
});

Variants

Every snackbar has a message, and AEC.snackbar() always adds a close button. The action is optional. Long messages wrap and move the action below the text.

Usage

Content

  • Message: say what just happened, in the past tense, for example Vehicle saved or Link copied. Keep it to a few words, and no more than one short sentence. Leave out the full stop on a fragment.
  • Action: one or two words, starting with a verb, such as View or Undo. Don't add OK or Dismiss: the close button already does that.
  • Don't use generic messages such as "Success!". Say what succeeded.

Accessibility

Status messages WCAG 4.1.3

Snackbars are rendered in a role="status", aria-live="polite" region, so screen readers announce them without moving focus.

Timing WCAG 2.2.1

The timer pauses on hover, and each snackbar has a close button. Never put the only way to do something inside a snackbar.

Focus WCAG 2.4.3

A snackbar doesn't take focus when it appears. Keyboard users can still reach the action and close button with Tab while it's on screen.

Close button name WCAG 4.1.2

The close button has aria-label="Dismiss", and its icon is hidden from assistive technology.

Contrast WCAG 1.4.3 · 1.4.11

The message and action need at least 4.5:1 against the snackbar. The close icon needs 3:1. These ratios are measured live in the active brand. The bar in the close-icon rows is a sample of the icon colour.
