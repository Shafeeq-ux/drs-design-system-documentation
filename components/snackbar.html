Snackbar

Briefly confirms the result of an action, such as Vehicle saved, with a message that disappears on its own.

4 Figma variants.aec-snackbar · AEC.snackbar()

Try it

// JavaScript API (components.js)
AEC.snackbar({
  message: 'Vehicle saved to your garage',
  action: 'View',
  onAction: () => location.assign('/garage'),
  timeout: 6000 // ms, default 6000
});

Usage

  • Use a snackbar for low-priority confirmations. Don't use it for errors that need action. Use an alert instead.
  • Keep the message to one short sentence, with at most one action.
  • Show one snackbar at a time.

Accessibility

Status messages WCAG 4.1.3

Snackbars are rendered in a role="status", aria-live="polite" region, so screen readers announce them without moving focus.

Timing WCAG 2.2.1

The timer pauses on hover, and each snackbar has a close button. Never put the only way to do something inside a snackbar.

Figma notes

  • The snackbar is light (bg/variant), where most systems use a dark one. An .aec-snackbar--inverse option is also available in code.
  • Figma has no close icon. The code adds one so people can dismiss the snackbar (WCAG 2.2.1).
