Radio button

Lets people choose exactly one option from a short list, with every option visible.

2 Figma component sets.aec-radio

Use radio buttons for two to six mutually exclusive options, for example a payment type or delivery method. For longer lists, use a select menu. For a single on/off choice, use a checkbox or switch.

Inline

For two or three short options, lay them out in a row with .aec-choice-list--row.

With a hint

Add .aec-fieldset__hint under the legend when the question needs a short explanation. Link it to the group with aria-describedby.

How would you like to get your vehicle?

You can change this until the day before delivery.

States

Each row is a value and each column is an interaction state. The colours come from the active brand's radio tokens (--aec-radio-color-* for unselected and --aec-radio-color-selected-* for selected), so switch the brand in the header to see how each one changes. Focus adds a 2px focus/default ring, 2px outside the ring. Pressed looks the same as hover, so it isn't shown.

Usage

Content

The legend asks the question. Each label is one possible answer.

  • Write the legend as a question or a short instruction, such as How would you like to pay?
  • Keep labels short and parallel: start each one the same way and keep them a similar length.
  • Use the description for one line of detail that helps people choose, such as a price or a condition.
  • Make sure the options cover every case. Add Other or I'm not sure if people might not fit any option.

Accessibility

Group with a legend WCAG 1.3.1

Wrap the group in <fieldset class="aec-fieldset"> with a <legend> that states the question. Give every radio in the group the same name.

Keyboard WCAG 2.1.1

Tab moves into the group, onto the selected option (or the first one if none is selected). Arrow keys move between options and select them, which is native browser behaviour. The whole group is one tab stop.

Target size WCAG 2.5.8

Wrap each radio and its text in <label class="aec-control"> so the whole row is clickable. The row is tall at this window width.

Focus visible WCAG 2.4.7

The focused radio shows a 2px focus/default ring on :focus-visible. Don't remove it.

Required groups WCAG 3.3.1

If nothing is selected on submit, show an error message under the legend and link it to the fieldset with aria-describedby.

Text contrast WCAG 1.4.3

Legend, label and description text need at least 4.5:1 against the background. These ratios are measured live in the active brand.

Figma notes

  • Hover and pressed look the same as default, and there are no selected + hover variants.
  • "Radio Group with Label" is a single radio with a label, not a group.
  • Selected uses dark grey (icon/default) rather than primary blue, consistent with checkbox and switch.
  • There is no error state for radio buttons in Figma. Show errors with a message under the legend.
