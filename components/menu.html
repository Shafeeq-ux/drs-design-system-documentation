Menu

Shows a list of options or actions in a panel that opens from a button or field.

Menu + Menu List item.aec-menu

A menu keeps secondary actions and choices out of the way until people need them. Use an action menu for commands, such as Save deal, and a selection menu to pick one value, such as a sort order. Items can have an icon, a description, a header and dividers. For a value submitted with a form, use a dropdown text field instead.

Action menu

Use role="menu" with menuitem children for commands.

Selection menu with search

For picking one value, use menuitemradio items. The selected item uses the selected typography and gets a tick. Turn on search for long lists.

Item states

Menu items have default, hover, pressed, selected and disabled states. Colours come from the active brand's list item tokens (--aec-list-item-color-*), so switch the brand in the header to compare them. Keyboard focus shows the hover background with a 3px focus/default bar on the leading edge.

Usage

  • Open the menu next to its trigger and keep it on screen. On small screens, consider a bottom sheet for long lists.
  • Close the menu after an action or a selection, and show the selected value on the trigger.
  • Don't put menus inside menus. Use a dialog or a separate page for deep choices.

Content

  • Start action labels with a verb: Save deal, Download summary.
  • Keep labels to one to four words in sentence case, with no end punctuation.
  • Use descriptions only when two items could be confused, and keep them to one line.
  • Write headers as short nouns: Price, Vehicle.

Accessibility

Trigger WCAG 4.1.2

The button has aria-haspopup="menu", aria-expanded and aria-controls.

Keyboard WCAG 2.1.1

Enter, Space or ↓ opens the menu and focuses the first item (↑ focuses the last). Arrows and Home/End move between items, Esc closes and returns focus, and Tab closes.

Focus visible WCAG 2.4.7

The focused item gets the hover background and a 3px focus/default bar. Figma has no focus state, so this is added in code.

Roles and selection WCAG 1.3.1

Use menuitem for actions and menuitemradio with aria-checked for a single choice. Mark unavailable items with aria-disabled="true" so they stay discoverable. Headers and dividers are role="presentation".

Form selects

For a value submitted with a form, prefer a native <select> styled as a dropdown text field.

Text contrast WCAG 1.4.3

Item text needs at least 4.5:1 against the item background in every state people can act on. Ratios are measured live in the active brand. Disabled items are exempt.
