Slider

Lets people pick a single value or a range by dragging along a track, for example a down payment or a price range.

2 Figma component sets.aec-slider · .aec-range

Sliders suit approximate values where people want to explore, such as how a down payment changes the monthly price. When the exact number matters, show the value and offer a text field as well.

States

The track and handle colours come from the active brand's slider tokens (--aec-slider-color-track-* and --aec-slider-color-handle-*), so switch the brand in the header to see how they change. When disabled, the selected track and handle turn grey and the cursor shows not-allowed. Keyboard focus adds a 2px focus/default ring around the handle; try it by tabbing to the examples above. Hover and pressed look the same as default.

Usage

Content

  • Write the title as a short noun phrase that names the value, such as Down payment or Price range.
  • Format the value the way people read it, with the currency symbol and thousands separators. Set it with data-format, for example ${v}.
  • Use the min and max labels to show the ends of the range. For a range slider, Min and Max are enough when the values are shown above.
  • If the slider changes a total elsewhere, such as the monthly payment, show that result close to the slider.

Accessibility

Native range input WCAG 4.1.2

Built on <input type="range">. components.js sets aria-valuetext to the formatted value, such as "$6,000", so screen readers don't read a bare number.

Keyboard WCAG 2.1.1

Tab moves to each handle. Arrow keys move by one step, Page Up and Page Down by a larger step, and Home and End jump to the ends.

Labels WCAG 1.3.1

Label single sliders with <label for>. Range sliders need an aria-label on each handle ("Minimum price", "Maximum price") and a group label.

Focus WCAG 2.4.7

The handle shows a 2px focus ring. This is added in code, because Figma has no focus state.

Dragging WCAG 2.5.7

Provide a non-drag alternative, such as a text field or the keyboard, for setting an exact value.

Announce results WCAG 4.1.3

If moving the slider updates a price elsewhere, announce the new total through an aria-live="polite" region once the value settles.

Text contrast WCAG 1.4.3

Text needs at least 4.5:1 against its background. These ratios are measured live in the active brand.
