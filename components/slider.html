Slider

Lets people pick a single value or a range by dragging along a track, for example a down payment or a price range.

2 Figma component sets.aec-slider · .aec-range

Sliders suit approximate values where people want to explore, such as how a down payment changes the monthly price. When the exact number matters, show the value and offer a text field as well.

Anatomy

  1. Title: body-1 bold, text/default.
  2. Value (optional): body-2 in a bg/variant pill.
  3. Track: 4px, border/default.
  4. Selected track: primary/default, or bg/disabled when disabled.
  5. Handle: a 24px white circle with a 1px primary/default border and shadow/s.
  6. Min / max labels (optional): body-3, text/subtle.

Accessibility

Native range input WCAG 4.1.2

Built on <input type="range">. Arrow keys, Page Up/Down and Home/End all work. components.js sets aria-valuetext to the formatted value, such as "$6,000".

Labels WCAG 1.3.1

Label single sliders with <label for>. Range sliders need an aria-label on each handle ("Minimum price", "Maximum price") and a group label.

Focus WCAG 2.4.7

The handle shows a 2px focus ring. This is added in code, because Figma has no focus state.

Dragging WCAG 2.5.7

Provide a non-drag alternative, such as a text field or the keyboard, for setting an exact value.

Figma notes

  • The handle's hover and pressed states look the same as default, and there is no focus state.
  • The titles and values use Inter and Avenir Next instead of Chevy Sans. The code uses the system font throughout.
  • The disabled state doesn't dim the title.
