Placement

Set data-placement to top (the default), bottom, left or right. Add -start or -end to top and bottom to align the tooltip to the trigger's edge. data-arrow="none" removes the pointer.

Usage

  • Keep tooltips to one or two short sentences. For longer or interactive content, such as links, use a modal or an expandable section.
  • Never hide information people need to complete a task inside a tooltip.
  • Every icon button should have a tooltip that repeats its accessible name.

Accessibility

Role and relationship WCAG 4.1.2

The tooltip has role="tooltip" and an id, and the trigger points to it with aria-describedby.

Hover and focus WCAG 1.4.13

The tooltip shows on hover and on keyboard focus, stays visible while the pointer is over it, and can be dismissed with Esc (components.js).

Focusable trigger WCAG 2.1.1

Only put tooltips on focusable elements, such as buttons and links, so keyboard users can reach them.

Figma notes

  • The placement property is called Arrow in the dark set and pointer in the light set, with values in a different order. The code uses data-placement for both.
  • The shadow is a raw effect, but its values match shadow/l exactly.
  • The light tooltip has no border, so on white backgrounds it is separated only by its shadow.
