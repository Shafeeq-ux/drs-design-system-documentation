Chip

Compact elements for showing status, filtering a list and representing removable selections.

6 Figma component sets.aec-chip

There are four kinds of chip. Information and plain chips are static labels. Selectable chips toggle filters. Dismissable chips show a chosen value that can be removed. The corner radius, sizes and colours come from each brand's chip tokens, so switch the brand in the header to compare them.

Information

A status label, such as In stock, Pending signature or Offer expired. It is subtle by default. Add --filled for stronger emphasis.

Plain

Selectable

A filter that toggles on and off. Selected chips fill with the brand's selected colour. Use it for vehicle filters such as body style or fuel type.

Dismissable

Shows a chosen value, such as an applied filter, that can be removed with the close button.

States

Information and plain chips are static, so they have no states. Selectable and dismissable chips take their state colours from the brand's chip tokens (--aec-chip-selectable-color-* and --aec-chip-dismissable-color-*). Focus adds a 2px focus/default ring, 2px outside the chip or its close button.

Selectable

Once selected, a chip keeps its selected colours on hover and press. It can still take focus and be disabled.

Dismissable

Hover and disabled apply to the whole chip. Focus goes to the close button, which is the only interactive part.

Spacing in a list

Wrap a set of chips in .aec-chip-list. Chips sit apart and wrap onto a new line when they run out of room.

Usage

Content

Chip labels are short. Write them in sentence case: brands that show uppercase chips apply it through their typography tokens.

Accessibility

Filter state WCAG 4.1.2

Selectable chips are <button aria-pressed>. Wrap a set in role="group" with an aria-label.

Remove buttons WCAG 2.4.6

Each close button needs a specific name, such as aria-label="Remove Silverado". After a chip is removed, focus moves to the next chip.

Keyboard WCAG 2.1.1

Each selectable chip and each close button is a tab stop, and works with Enter or Space. Information and plain chips are not focusable.

Status is not colour alone WCAG 1.4.1

The status word carries the meaning. Plain chips also add an icon.

Target size WCAG 2.5.8

The close button is small. Keep the standard gap between dismissable chips so each one can be tapped on its own.

Contrast WCAG 1.4.3

Filled chips generally have the strongest contrast. Some subtle chips fall below 4.5:1 in some brands, so check the table below. Until darker on-subtle tokens exist, use filled chips wherever the status text is essential.

Text contrast WCAG 1.4.3

Chip text needs at least 4.5:1 against its background. These ratios are measured live from the chips below in the active brand. Disabled chips are exempt.

Figma notes

  • Inverse selectable chip, disabled and selected: the background and text are both #666666, so the label can't be read. The code uses inverse/text/variant for the text.
  • Dismissable active looks the same as hover. Selectable pressed adds a blue border.
  • The */on-subtle colours are below 4.5:1 on their */subtle backgrounds (warning 2.87, error 3.76, success 3.78, primary 4.00). Proposal: darker on-subtle tokens, for example warning #7a5a1e.
  • Chips have square corners, while buttons are rounded to 8px. Check that this difference is intended.
  • The size names don't line up across chip types. The default information chip uses the container-small tokens, while the default selectable chip uses container-medium.
