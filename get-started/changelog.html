Changelog

Notable changes to tokens, components and this site.

v1.3.0 Docs depth & icon fonts

  • Brand icon fonts: each brand's IcoMoon font replaces the SVG icons across the site, and the glyph follows the brand. The Icons page lets you browse each brand's set, compare glyphs across brands and download each font as a zip (also listed on Brand tokens). New markup: <span class="aec-icon" data-icon="car">.
  • Component pages now have live state matrices (default, hover, focus, pressed, disabled, loading and more), blue spacing marks and size tables measured from the real components, do and don't guidance, and contrast tables calculated for the active brand.
  • New static state classes .is-hover, .is-pressed, .is-focus and .is-loading (or aria-busy="true") for showing states in docs and prototypes.
  • The Overview page shows live component thumbnails, and the Team avatars meet contrast.
  • The token docs now explain the two layers in the brand files: --aec-* custom properties, and .drp-* classes for typography and component metrics.
  • For designers lists only the two libraries in use: the design foundation and the components library.

v1.2.0 Multi-brand

  • Six brands from the DRS token files: DRS Base (the new default), Chevrolet, GMC, Buick, Cadillac and Car Bravo. The new Chevrolet tokens replace the earlier Figma JSON values.
  • A brand menu in the header re-themes the whole site. The choice is remembered, and ?brand=<id> links to a page in a specific brand. Every example also has its own brand picker.
  • New Multi-brand page: every brand side by side, how the token layers fit together and how to add a brand.
  • New Brand tokens page: download each brand as drop-in .css, .vars.css or .json, and compare all ~3,600 tokens across brands.
  • New Theme builder: create or edit a brand with quick colour, shape and type controls, a palette view and the full token list. It has a live preview, contrast checks, undo, import and export, and share links.
  • New css/brands/<id>.css runtime files and css/brand-components.css, generated by scripts/build-brands.mjs. Foundation pages now show the active brand's values.

v1.1.0 Patterns

  • New Patterns section with 34 pages, from the DR 2.0 – SC GM Chevy Components Figma library.
  • New css/patterns.css: page template (container queries), left navigation, page header, stepper, footers, notifications, live session, rich tooltip, side sheets, signature, bottom sheets, dialogs, Mathbox, the checkout card system, form layouts, calendar, vehicle selector, gallery, confirmation and in-store patterns.
  • components.js adds AEC.toast(), signature pads, OTP inputs, an accessible calendar, Add/Added card toggles and generic radio groups.
  • The hidden attribute now always hides components.

v1.0.0 Initial release

  • Tokens generated from the Figma library: 83 colours, 11 type styles, 30 spacing, 5 radius, 8 border width and 7 elevation tokens.
  • DM Sans replaces Chevy Sans for the web, with mobile-first responsive type.
  • Foundation pages: colour, typography, spacing, border, elevation, icons (196) and illustrations.
  • 26 component pages, each with variants, states, anatomy, guidelines and accessibility notes.
