Get started

For designers

The design system lives in two Figma libraries. Together they are the source of truth, and this site documents them and mirrors them in code.

LibraryContainsDocumented in
DR 2.0 – SC GM Chevrolet Design FoundationStyles (colour, type, elevation, border, spacing), icons, illustrations and the core componentsFoundations and Components
DR 2.0 – SC GM Chevy ComponentsLarger composite components: page template, navigation, sheets, cards, Mathbox, forms and screensPatterns

Enable the library

  1. In your Figma file, open Assets → Libraries (Alt/Option + 3, then the book icon).
  2. Turn on DR 2.0 – SC GM Chevrolet Design Foundation and DR 2.0 – SC GM Chevy Components. These two files are all you need.
  3. Use the colour, text and effect styles. Don't use raw hex values, so that designs stay linked to tokens.

Pages marked 🚧 in Figma are still in progress and aren't documented here yet. See Component status. The components library is organised by checkout area, such as navigation, sheets, cards, forms and screens. Each one is covered under Patterns.

Handoff

  • Colour styles map to CSS custom properties. text/subtle in Figma is --aec-color-text-subtle in code.
  • Text styles and component sizes map to .drp-* classes in the brand files, such as .drp-typography-heading-1 or .drp-button-contained-container-bg-large. On this site they are also available as --drp-* custom properties. See Use tokens.
  • Brand differences (colour, fonts, corners, letter case) come from the brand token files, not from the Figma components. See Multi-brand.
  • Component variant properties map to CSS modifiers. For example, Button style=outline becomes .aec-btn--outline.
  • Each component page has a View in Figma link to its source page.
