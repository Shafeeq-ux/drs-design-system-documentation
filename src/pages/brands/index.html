How brand tokens work

1

Brand file

tokens/brands/source/<brand>.css is exported from Figma variables. It contains .drp-* classes (component sizes, typography and button colours) and a block of --aec-* custom properties (semantic and component colours).

2

Runtime tokens

npm run build converts every class value into a custom property (for example --drp-button-contained-container-bg-large-border-radius). It merges the brand over DRS Base so nothing is missing, then scopes the result to [data-brand="<brand>"].

3

Components

brand-components.css maps those tokens onto the .aec-* components. A button's colour comes from emphasis × style × state, its size and corners from the size tokens, and its font and case from the button typography tokens.

Token layerExampleDrives
Semantic colour--aec-color-primary-defaultLinks, focus rings, spinners, the docs accent and anything else that uses the primary colour
Component colour--aec-chip-selectable-color-bg-selected-defaultOne state of one component
Component metric--drp-input-standard-outlined-container-bg-large-heightHeights, padding, gaps, corner radius and border widths
Component type--drp-button-contained-typography-large-text-transformFont, size, weight and letter case per component
Type scale--drp-typography-heading-1-font-sizeThe .aec-heading-*, .aec-body-* and .aec-display-* styles, per breakpoint

Use a brand in code

Load the base tokens, one or more brand files and the component CSS, then set the brand on any element. The brand applies to everything inside that element.

<link rel="stylesheet" href="css/tokens.css">
<link rel="stylesheet" href="css/brands/gmc.css">
<link rel="stylesheet" href="css/components.css">
<link rel="stylesheet" href="css/brand-components.css">

<html data-brand="gmc">
  …
  <!-- one section in another brand -->
  <div data-brand="cadillac"><button class="aec-btn aec-btn--primary">Reserve</button></div>
</html>

Teams that consume the original classes can keep using the drop-in brand files, such as <button class="drp-button-contained-container-bg-large drp-button-contained-color-primary-filled drp-button-contained-typography-large">. Download them from Brand tokens.

Brand fonts

Brand typefaces are licensed and are not served from this public site. Each family falls back to a free Google Fonts substitute. On a machine that has the real font installed, the real font is used.

Add a brand

  1. Create the tokens. Export them from Figma, or design them in the Theme builder and download <id>.css.
  2. Save the file as tokens/brands/source/<id>.css.
  3. Add { "id": "<id>", "name": "…", "file": "<id>.css" } to tokens/brands/brands.json. Add any new fonts with a public substitute.
  4. Run npm run build. The header menu, this page, Brand tokens and the Theme builder pick up the new brand automatically.

Token notes

  • carbravo.css is byte-for-byte identical to chevrolet.css, so Car Bravo looks the same as Chevrolet for now.
  • Twelve selectors such as .drp-typography-mobile-heading-1 regular contain a space, so in the original files they match nothing. They are kept here as --drp-typography-mobile-heading-1-regular-*.
  • Some colour tokens have the value none (for example the selected border of selectable chips). They are treated as transparent, and box-shadow: 0 is treated as none.
  • DRS Base has no mobile-* heading styles, so its headings use the same size at every breakpoint below 768px.
  • The weekly calendar classes in base.css use fixed colours rather than tokens, so they don't change with the brand.
