Text field

Lets people enter and edit a short piece of text, such as a name, email, ZIP code or VIN. The same box is used for dropdown selects.

4 published Figma sets.aec-field

There are two published styles. Standard has the label above an outlined box and is the default for forms. Material has a floating label inside a filled box, for compact layouts. Both support prefix and suffix content, icons, assistive text and a dropdown type.

Usage

Phone number
Do
Always show a visible label, and use the placeholder only for an example format.
Don't
Don't use the placeholder as the label. It disappears as soon as people start typing.
  • Match the field's width to the expected input, for example a short width for ZIP code.
  • Use the right type, inputmode and autocomplete so mobile keyboards and autofill work.
  • Validate when the field loses focus or the form is submitted, not on every keystroke.
  • Write error messages that say how to fix the problem: Enter a 17-character VIN, not Invalid VIN.

Accessibility

Labels WCAG 1.3.1 · 3.3.2

Every input needs a <label for>. Required fields also get the required attribute. The visual * is aria-hidden.

Errors WCAG 3.3.1

Set aria-invalid="true" and connect the message with aria-describedby. Errors are shown with an icon and text, not colour alone.

Focus WCAG 2.4.7

Focus turns the border primary/default and adds the 2px focus ring for keyboard users.

Input purpose WCAG 1.3.5

Use autocomplete values (given-name, email, postal-code, tel) on personal-data fields.
