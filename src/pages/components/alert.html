Alert

Displays an important message about the current page or task. It stays visible until the issue is resolved or the person dismisses it.

4 statuses.aec-alert

Use an alert for messages tied to the content in front of the user, such as Your credit application was approved. For brief confirmations of an action, use a snackbar. For neutral announcements at the top of a page, use a banner.

Anatomy

  1. Container: bg/default, 1px border/default, shadow/m, square corners and 16px padding. Add .aec-alert--flat to remove the shadow inside cards.
  2. Status accent: a 2px left border in the status colour.
  3. Icon: 24px, in the status colour.
  4. Title (optional): body-1 bold, text/default.
  5. Message: body-2, text/subtle.
  6. Link (optional) and close button (optional).

Accessibility

Announcements WCAG 4.1.3

Use role="alert" only for urgent errors that appear dynamically. Use role="status" for success, info and warning. Alerts present when the page loads need neither.

Not colour alone WCAG 1.4.1

Each status has its own icon and message, so meaning doesn't depend on the accent colour.

Dismissing WCAG 2.1.1

The close button is a labelled icon button. When the alert is removed, focus moves to the next element.

Figma notes

  • Every status uses the same placeholder icon. The code uses status icons from the library (state-success, warning, state-error, info).
  • Information uses grey #666666 in Figma. The code uses info/default. Confirm which is intended.
  • The shadow is a raw effect, but its values match shadow/m exactly.
