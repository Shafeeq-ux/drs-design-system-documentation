Components · Inputs

Checkbox

Lets people turn an option on or off, or choose any number of options from a list.

3 Figma component sets.aec-checkbox

Use a checkbox when each option is independent, or when a single choice needs explicit consent, such as agreeing to terms. For one choice from a list, use a radio button. For a setting that takes effect immediately, use a switch.

Variants

Indeterminate

Use the indeterminate state for a parent checkbox when some, but not all, of its children are selected. Set it with JavaScript: input.indeterminate = true. There is no HTML attribute for it.

Group with an error

Put related checkboxes in a <fieldset> with a <legend>. When a required consent box is left empty, mark it invalid and show the message under it.

States

Each row is a value and each column is an interaction state. The colours come from the active brand's checkbox tokens (--aec-checkbox-color-<value>-<part>-<state>, where value is empty for unchecked, selected for checked and intermediate for indeterminate), so switch the brand in the header to see how each one changes. Focus adds a 2px focus/default ring, 2px outside the box. In some brands, pressing an unchecked box previews the check.

Error

Error uses the brand's --aec-color-error-default border. It applies to both values; disabled boxes never show an error.

Usage

Content

The label says what happens when the box is checked. Keep it short and put extra detail in the description.

  • Write labels in sentence case, with no full stop at the end.
  • Use the description for one short line of detail, such as what's included or why an option is unavailable.
  • Use the count only in filters, to show how many results an option will return.
  • Write error messages that say what to do, such as Agree to the financing terms to continue.

Accessibility

Native input WCAG 4.1.2

.aec-checkbox styles a real <input type="checkbox">, so the checked, indeterminate and disabled states are announced automatically. Don't rebuild it with role="checkbox" on a div.

Label in a target WCAG 2.5.8

Wrap the input and label text in <label class="aec-control"> so the whole row is clickable. The row is tall at this window width.

Keyboard WCAG 2.1.1

Tab moves focus to the box and Space toggles it. Each checkbox is its own tab stop. Focus shows a 2px focus/default ring on :focus-visible.

Groups WCAG 1.3.1

Wrap related checkboxes in <fieldset class="aec-fieldset"> with a <legend> that asks the question. Screen readers read the legend before each option.

Errors WCAG 3.3.1

For a required consent box, set aria-invalid="true" and link an error message with aria-describedby. The error icon and text mean colour isn't the only signal.

Indeterminate

The browser announces a parent checkbox as "mixed" when indeterminate is set. Update it whenever a child changes.

Text contrast WCAG 1.4.3

Label and description text need at least 4.5:1 against the background. These ratios are measured live in the active brand. Disabled checkboxes are exempt.
