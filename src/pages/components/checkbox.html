Components · Inputs

Checkbox

Lets people turn an option on or off, or choose any number of options from a list.

3 Figma component sets.aec-checkbox

Use a checkbox when each option is independent, or when a single choice needs explicit consent, such as agreeing to terms. For one choice from a list, use a radio button. For a setting that takes effect immediately, use a switch.

Variants

Indeterminate

Use the indeterminate state for a parent checkbox when some, but not all, of its children are selected. Set it with JavaScript: input.indeterminate = true.

States

Checked
Indeterminate

The checked state is a white box with a dark check, not a filled box. While the mouse is pressed on an unchecked box, a grey check previews the selection.

Usage

Do
Write labels as positive statements that describe what happens when the box is checked.
Don't
Don't use negative or double-negative labels.
  • Stack options vertically, one per line, so they're easy to scan.
  • Group related checkboxes in a <fieldset> with a <legend>.
  • Don't make a checkbox submit a form or trigger navigation.

Accessibility

Native input WCAG 4.1.2

.aec-checkbox styles a real <input type="checkbox">, so the checked, indeterminate and disabled states are announced automatically.

Label in a target WCAG 2.5.8

Wrap the input and label text in <label class="aec-control"> so the whole row is clickable. Each row is at least 40px tall.

Keyboard WCAG 2.1.1

Tab moves focus to the box and Space toggles it. Focus shows a 2px ring.

Errors WCAG 3.3.1

For a required consent box, set aria-invalid="true" and link an error message with aria-describedby.

Figma notes

  • Hover looks the same as default in Figma. Pressed previews a grey check.
  • There are two overlapping label sets, "Checkbox with Label" and "Checkbox with Label new". The code follows "new".
  • In Figma, a disabled row keeps its label in text/default. The code greys the label to text/disabled so the state is clear.
  • The 2px box radius and the #373637 dash colour don't match any token.
