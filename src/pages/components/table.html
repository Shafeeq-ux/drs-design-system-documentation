Specification

  • Header: bg/variant, body-2 demi, text/subtle, with optional sort buttons.
  • Cell: body-2, text/default, padding 12/8px (16px at the outer edges), 1px border/default row dividers.
  • Selected row: primary/subtle.
  • Numbers: right-aligned with tabular figures (.aec-num).

Accessibility

Semantics WCAG 1.3.1

Use a real <table> with a <caption> and scope on header cells. Sorted columns use aria-sort.

Scrolling WCAG 1.4.10

Wide tables scroll inside .aec-table-wrap. Give the wrapper tabindex="0" and a label so keyboard users can scroll it.

Figma notes

  • This is a legacy component, with an off-palette grey scale (#f1f1f3, #60616c, #e4e4e7), Space/Padding/* variables and an older checkbox. The code maps it to current tokens and uses the current checkbox.
  • The size order is inconsistent: Small controls are taller than Default ones.
  • Figma has no hover or selected row states. The code adds them.
  • There are typos in Figma ("Checkbox Dropdawn", "Expended").
