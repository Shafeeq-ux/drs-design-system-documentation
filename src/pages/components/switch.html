Components · Inputs

Switch

Turns a single setting on or off, with immediate effect.

2 Figma component sets.aec-switch

Use a switch when a change applies straight away, without a save step, for example Show monthly price. If the choice is only applied when a form is submitted, use a checkbox.

Variants

Label position

In settings lists, put the label first and the switch at the end of the row, with .aec-control--between.

States

Each row is a value and each column is an interaction state. The colours come from the active brand's switch tokens (--aec-switch-color-track-* and --aec-switch-color-handle-*, with -selected- for on), so switch the brand in the header to see how each one changes. Focus adds a 2px focus/default ring, 2px outside the track. Pressed looks the same as hover, so it isn't shown.

Size and spacing

There is one size. The blue marks are measured from the real switch in the active brand, so they change when you switch brands. The row grows on small screens to give a larger touch target, so its height depends on the window width.

Usage

Content

  • Name the setting, not the action: Show monthly payment, not Turn on monthly payment.
  • Don't add "On" or "Off" text next to the switch. The state is already shown visually and announced.
  • Write labels in sentence case, with no full stop at the end.
  • Use the description to say what the setting affects, such as Estimated for ZIP 48226.

Accessibility

Role WCAG 4.1.2

Use <input type="checkbox" role="switch">. Screen readers then announce "switch, on" or "switch, off".

Keyboard WCAG 2.1.1

Tab moves focus to the switch and Space toggles it. Focus shows the 2px focus/default ring around the track.

Target size WCAG 2.5.8

Wrap the switch and its label in <label class="aec-control"> so the whole row is clickable. The row is tall at this window width.

Not by colour alone WCAG 1.4.1

The handle's position shows the state as well as the fill.

Announce changes WCAG 4.1.3

If the switch updates content elsewhere, such as prices, announce the change through an aria-live="polite" region.

Text contrast WCAG 1.4.3

Label and description text need at least 4.5:1 against the background. These ratios are measured live in the active brand.
