Components · Inputs

Switch

Turns a single setting on or off, with immediate effect.

2 Figma component sets.aec-switch

Use a switch when a change applies straight away, without a save step, for example Show monthly price. If the choice is only applied when a form is submitted, use a checkbox.

Variants

Label position

In settings lists, put the label first and the switch at the end of the row, with .aec-control--between.

States

Off
On
Focus
Disabled off
Disabled on

Anatomy

1 2 3
  1. Track48×24px, fully rounded, 1px secondary/default border. Filled when on.
  2. Handle20px circle with shadow/s. Dark when off, white when on.
  3. Labelbody-2, 8px from the track.

Content

  • Name the setting, not the action: Show monthly payment, not Turn on monthly payment.
  • Don't add "On" or "Off" text next to the switch. The state is already shown visually and announced.

Accessibility

Role WCAG 4.1.2

Use <input type="checkbox" role="switch">. Screen readers then announce "switch, on" or "switch, off".

Keyboard WCAG 2.1.1

Space toggles the switch. Focus shows the 2px ring around the track.

Not by colour alone WCAG 1.4.1

The handle's position shows the state as well as the fill.

Announce changes WCAG 4.1.3

If the switch updates content elsewhere, such as prices, announce the change through an aria-live="polite" region.

Figma notes

  • "On" is dark (secondary/default), not primary blue.
  • The handle shadow is a raw effect, not an effect style. The code uses shadow/s.
  • The track border is 1px here, but checkbox and radio use 1.5px.
