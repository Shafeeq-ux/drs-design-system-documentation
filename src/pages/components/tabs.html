Tabs

Switches between related views on the same page without leaving it, for example Finance, Lease and Cash.

6 styles.aec-tabs

Tabs organise related content into views at the same level, so people can switch without leaving the page. There are six styles: underlined, inset, contained, segment, stacked and vertical. Use tabs for views, not for steps in a process, and not for navigation to other pages.

The default. Text tabs with an underline beneath each label (Figma: Underlined – Inside).

States

Each style has default, hover, pressed, selected and disabled states. Colours come from the active brand's tab bar tokens (--aec-tabbar-<style>-tab-item-color-*), so switch the brand in the header to see how each one changes. Keyboard focus adds a 2px inset focus/default ring; it isn't shown here because it only appears on real keyboard focus.

Usage

Content

  • Use one or two words that name the content: Finance, Specs, Documents.
  • Write in sentence case. Brands that show uppercase tabs apply it through their typography tokens.
  • Keep labels parallel, for example all nouns. Don't mix nouns and actions.
  • Don't truncate labels. If they don't fit, the list scrolls sideways; shorten the labels or use fewer tabs.
  • A count can follow the label, such as Used (58), when it helps people choose.

Accessibility

Roles WCAG 4.1.2

Use role="tablist", tab and tabpanel. Each tab has aria-selected and aria-controls, and each panel has aria-labelledby. Give the tab list an aria-label.

Keyboard WCAG 2.1.1

Tab moves into the tab list. Arrow keys move between tabs and activate them (up and down for vertical tabs), and Home/End jump to the first or last tab. Tab again moves into the panel.

Focus visible WCAG 2.4.7

Tabs show a 2px inset focus ring. This is added in code, because Figma has no focus state.

Roving tabindex

Only the selected tab is in the tab order (tabindex="0"); the others get tabindex="-1". The script does this for you. Disabled tabs are skipped by the arrow keys.

Vertical tabs WCAG 1.3.1

Add aria-orientation="vertical" to the tab list so screen readers announce the right arrow keys.

Text contrast WCAG 1.4.3

Tab labels need at least 4.5:1 against their background, selected or not. These ratios are measured live in the active brand. Disabled tabs are exempt.

Do / don't

Figma notes

  • Medium tab items mix three typefaces (Avenir LT Pro, Avenir Next and Chevy Sans), and some medium labels are all caps. The code uses one family in sentence case.
  • Inset tab labels are demi and one size smaller than the other styles, and their disabled text uses bg/disabled.
  • Hover and active look the same in the contained, segment and vertical styles.
