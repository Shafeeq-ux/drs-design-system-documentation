Form control

The label block that sits next to a checkbox, radio button or switch: a label, an optional count and an optional description.

Figma base component.aec-control · .aec-form-label

Form control is not used on its own. It is the shared row that makes a checkbox, radio button or switch clickable along its whole width, and keeps their labels consistent. .aec-control is the row; .aec-form-label is the text block inside it.

Variants

Layouts

.aec-control--reverse puts the control after the label. .aec-control--between pushes the control to the far end of a full-width row, which suits settings lists.

States

The label block has two states. When its control is disabled, the label, count and description all change to text/disabled and the row shows a not-allowed cursor. Hover, focus and pressed only change the control itself; see each control's page for those.

Size and spacing

Two label sizes. Medium is the default. The blue marks are measured from the real rows in the active brand. The row is taller on small screens to give a larger touch target, so its height depends on the window width.

Markup

<label class="aec-control">
  <input class="aec-checkbox" type="checkbox" name="plan">
  <span class="aec-form-label">
    <span class="aec-form-label__text">Protection plan <span class="aec-form-label__count">(3)</span></span>
    <span class="aec-form-label__desc">Covers parts and labour for 5 years</span>
  </span>
</label>

Modifiers: .aec-control--reverse puts the control after the label. .aec-control--between pushes the control to the far end of a full-width row.

Usage

Content

  • Label: a few words in sentence case, with no full stop. Say what the option is or what happens when it's selected.
  • Count: a number in brackets, such as "(24)". Only use it where it helps people narrow results.
  • Description: one line of helper text that helps people decide, such as what's included, a price or why the option is unavailable.
  • Keep links out of the label. Clicking the label toggles the control, so a link inside it is easy to hit by mistake. Put links in the description or after the group.

Accessibility

Label in name WCAG 2.5.3

Because the input sits inside the <label>, the label text, count and description all become the control's accessible name. For long descriptions, move them out of the label and reference them with aria-describedby.

Target size WCAG 2.5.8

The whole row is the click target. It is tall at this window width, and taller on small screens.

Disabled text

Disabled labels are exempt from contrast rules, but say why an option is unavailable in the description.

Text contrast WCAG 1.4.3

Text needs at least 4.5:1 against the background. These ratios are measured live in the active brand.
