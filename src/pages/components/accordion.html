Accordion

Shows and hides sections of related content, so people can expand only what they need, for example FAQs or the details of a protection plan.

Usage

  • Write headers as clear questions or labels, so people can tell what's inside without opening it.
  • Don't hide critical information, such as pricing or required steps, in a collapsed section.
  • For switching between parallel views, use tabs.

Accessibility

Structure WCAG 1.3.1

Each trigger is a <button> inside a heading at the right level. Its aria-expanded state and aria-controls point to the panel.

Keyboard WCAG 2.1.1

Tab moves between headers, and Enter or Space toggles a section. Focus shows a 2px inset ring.

Figma notes

  • All 8 Figma variants look identical: no hover, pressed or disabled styling, and expand=on has no panel. The states above are proposed in code using tokens.
  • The title uses Avenir LT Pro Heavy in pure black (#000). The code uses body-1 bold with text/default.
  • The divider is #dedede. The code uses border/default.
