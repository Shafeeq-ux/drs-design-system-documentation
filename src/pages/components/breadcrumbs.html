Breadcrumbs

Shows where the current page sits in the site hierarchy and lets people move back up a level.

2 Figma component sets.aec-breadcrumbs

A breadcrumb trail lists the pages above the current one, from the top level down. Each ancestor is a link, and the last item is the current page, which isn't a link. Use breadcrumbs on shopping and content pages that sit two or more levels deep. Don't use them in linear flows such as checkout; use a progress stepper there.

States

Ancestor links have default, hover and pressed states. The colours come from the active brand's breadcrumb tokens (--aec-breadcrumb-color-text-*), so switch the brand in the header to compare them. On real hover the link is also underlined, so it isn't shown by colour alone. Keyboard focus adds a 2px focus/default ring. The current page has no interactive states.

The forced hover column shows the colour change only. The underline appears on real hover.

Place breadcrumbs at the top of the page, above the page title. The trail wraps onto a second line when it doesn't fit.

Usage

  • Use breadcrumbs on pages two or more levels deep. Don't use them on the home page.
  • On mobile, consider showing only a back link to the parent page.
  • Breadcrumbs are a secondary aid. Keep the main navigation as well.

Content

  • Use the page title for each crumb, in sentence case.
  • Keep each crumb short. If a title is long, shorten it consistently across the site.
  • Don't add a separate "You are here" label. The trail and the landmark name explain it.

Accessibility

Landmark WCAG 1.3.1 · 2.4.8

Wrap the list in <nav aria-label="Breadcrumb"> and use an ordered list. Mark the current page with aria-current="page".

Separators

Separators are drawn in CSS, so screen readers don't announce them.

Keyboard WCAG 2.1.1

Each ancestor is a normal link, so Tab moves through them and Enter follows them. The "…" button opens with Enter or Space. After it expands, move focus to the first revealed link so keyboard users don't lose their place.

Collapsed levels WCAG 4.1.2

Give the "…" button an aria-label that says what it does, such as "Show 2 more levels".

Links not by colour alone WCAG 1.4.1

The trail's position and separators show that crumbs are links, and hover adds an underline.

Text contrast WCAG 1.4.3

Breadcrumb text is small, so it needs at least 4.5:1 against the page. These ratios are measured live in the active brand.

Do / don't

Figma notes

  • The current-page crumb has hover and pressed states in Figma. In code it isn't a link.
  • In the 5+ variant, the last crumb is medium weight instead of bold.
  • Figma shows no underline on hover. The code adds one so links aren't shown by colour alone.
  • The brand files define --aec-breadcrumb-color-text-disabled, but there's no disabled crumb in code. Crumbs are always links or the current page.
