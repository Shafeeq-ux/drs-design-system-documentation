Components · Navigation

Header

The app's top bar, with the brand logo, the dealership name and the shopper's account menu.

Web and mobile.aec-header

The header tells shoppers whose checkout they are in and gives them a way into their account. It has three parts: a logo slot for the OEM or dealer logo, the dealership name and an account button that opens a menu. It appears once, at the top of every checkout page. This page documents the product header, .aec-header, not the header of this documentation site.

Default

Riverside Motors

The logo is a placeholder. Each OEM or dealer supplies its own.

Variants

The header has no visual variants. What changes is the content of the account button and how much room the dealer name has. The colours come from the active brand's --aec-header-color-* tokens, so some brands use a dark header. Switch the brand to see it.

States

The account button is the only interactive part. On hover it gets a bg/variant background. On keyboard focus it shows a 2px focus/default ring, 2px outside the button. While the menu is open it has aria-expanded="true". Hover or tab to the account button in the example above to see them. The docs can't show these states side by side yet, because the button has no static state classes.

Usage

  • Use one header, at the top of every checkout page, including on mobile.
  • Keep it to the logo, the dealer name and the account button. Put navigation and steps in the page, for example in tabs or breadcrumbs.
  • Link the logo and dealer name to the start of the checkout or the dealer's home page.

Do / don't: usage

Accessibility

Landmark WCAG 1.3.1

Use a single <header> landmark and put a "Skip to content" link before it.

Account button WCAG 4.1.2

The account button opens a menu and needs a name that includes the person, such as "Account, Alex Morgan". Give it aria-haspopup="menu", aria-controls and an aria-expanded state that matches the menu.

Keyboard WCAG 2.1.1

Enter, Space or the down arrow opens the menu and moves focus to the first item. Arrow keys move between items, and Esc closes the menu and returns focus to the button.

Logo WCAG 1.1.1

Give the logo the brand name as its text alternative. When the logo and dealer name are one link, the link's name is both, for example "Brand logo, Riverside Motors".

Target size WCAG 2.5.8

The account button is tall in this brand, more than the 24×24px minimum.

Text contrast WCAG 1.4.3

The dealer name needs at least 4.5:1 against the header. These ratios are measured live in the active brand, including brands with a dark header.
