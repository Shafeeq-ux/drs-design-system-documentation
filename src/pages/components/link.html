Link

Takes people to another page, or to another place on the same page.

2 Figma component sets.aec-link

Links are always underlined, so they can be recognised without relying on colour. Use a link for navigation and a button for actions. Inside running text, a link inherits the surrounding font size.

States

Links have default, hover, focus and disabled states. Pressed looks the same as hover, so it isn't shown. The colours come from the brand's link tokens (--aec-link-color-<variant>-text-<state> and -icon-<state>). Neutral links also get a thicker underline on hover, because their hover colour can be the same as the default. Focus adds a 2px focus/default ring.

Loading

When a link starts something that takes a moment, such as loading a quote, the label can be swapped for a spinner. The underline is removed while it loads.

Inside a <p> or <li>, a link takes the font size and line height of the surrounding text, whatever its size class.

Usage

Content

The link text should tell people where they will go. Write it in sentence case and keep it short.

When a link opens a new tab, add the external-link icon and "(opens in a new tab)" as visually hidden text.

Accessibility

Link purpose WCAG 2.4.4

The text alone, or together with its sentence, should make the destination clear.

Use of colour WCAG 1.4.1

Links stay underlined, so they don't rely on colour to stand out from text.

Disabled links

A link can't be truly disabled. Remove the href and add aria-disabled="true", or better, render plain text.

Right element WCAG 4.1.2

Use <a href> for navigation. It is reached with Tab and followed with Enter. A link styled with .aec-link on a <button> is still a button to assistive technology, so only do this for actions.

Focus visible WCAG 2.4.7

Links show a 2px focus/default ring on :focus-visible. Don't remove it.

New tabs WCAG 3.2.5

Tell people before a link opens a new tab, with an icon and visually hidden text. Use rel="noopener" with target="_blank".

Text contrast WCAG 1.4.3

Link text needs at least 4.5:1 against its background. These ratios are measured live in the active brand. Disabled links are exempt.
