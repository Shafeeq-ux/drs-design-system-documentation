Link

Takes people to another page, or to another place on the same page.

2 Figma component sets.aec-link

Links are always underlined, so they can be recognised without relying on colour. Use a link for navigation and a button for actions. Inside running text, a link inherits the surrounding font size.

Content

  • Make the link text describe the destination: View financing options, not Click here.
  • Add an external-link icon and "(opens in a new tab)" to visually hidden text when a link opens a new tab.

Accessibility

Link purpose WCAG 2.4.4

The text alone, or together with its sentence, should make the destination clear.

Use of colour WCAG 1.4.1

Links stay underlined, so they don't rely on colour to stand out from text.

Disabled links

A link can't be truly disabled. Remove the href and add aria-disabled="true", or better, render plain text.

Figma notes

  • The brand style is identical to primary, so the code has one primary link.
  • Neutral has no hover colour change. The code thickens the underline on hover instead.
  • The Inverse loading spinner is blue in Figma.
