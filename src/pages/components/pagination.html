Accessibility

Landmark and current page WCAG 1.3.1 · 4.1.2

Use <nav aria-label>, mark the current page with aria-current="page", and label the arrow links ("Previous page").

Target size WCAG 2.5.8

Items are 32px, with an 8px gap between them.

Figma notes

  • Legacy colours (#494dac, #484951, #60616c, #f1f1f3, #cccdd1), Space/Padding/* and Primary/colorPrimary variables, and the Desktop/Normal text style.
  • The page-size control is a Standard button in Figma. The code uses a native select so it's accessible.
  • The 6px radius has no token.
