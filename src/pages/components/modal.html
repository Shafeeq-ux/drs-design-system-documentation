Usage

  • Use a modal to confirm destructive or important actions, and for short focused tasks.
  • Use a right sheet for supporting detail that people compare with the page, such as a payment breakdown.
  • Don't stack modals, and don't open them without a user action.

Accessibility

Native dialog WCAG 2.4.3 · 2.1.2

Built on <dialog> with showModal(). Focus is trapped in the dialog, the page behind is inert, Esc closes it, and focus returns to the trigger afterwards.

Name WCAG 4.1.2

Point aria-labelledby at the title.

Closing

Clicking the backdrop closes the dialog, except when it has data-static. Use that for forms with unsaved changes.

Figma notes

  • The header divider uses #d2d2d2 or #dedede, neither of which is a token. The code uses border/default.
  • Figma has no shadow or backdrop. The code adds shadow/2xl and backdrop/default.
  • The 20px bold title has no text style. The code uses heading-4.
