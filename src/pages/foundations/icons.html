Foundations

Icons

Each brand has its own icon font, built in IcoMoon. Icon names are shared across brands, but each brand draws its own glyphs. Switch the brand, and every icon on the site switches with it.

Same name, every brand

The same markup renders a different glyph in each brand.

Downloads

Each zip is the IcoMoon export for that brand. It contains the font in TTF, WOFF, EOT and SVG formats, style.css with an .icon-<name> class for every glyph, selection.json to re-import into IcoMoon, and a demo page.

Usage

Name the icon with data-icon. The glyph and font come from the nearest [data-brand], so the same markup is correct in every brand. Icons inherit color. Set the size with a size modifier.

<span class="aec-icon aec-icon--24" data-icon="calendar-check" aria-hidden="true"></span>

/* colour with an icon token */
.my-icon { color: var(--aec-color-icon-variant); }

Existing markup that points at an SVG still works. style="--aec-icon-src:url(/assets/icons/car.svg)" is swapped for the brand glyph automatically, and it falls back to the SVG when no font has that icon.

Apps that use the IcoMoon export directly can load the brand's style.css from the zip and use its classes, for example <i class="icon-car" aria-hidden="true"></i>. That approach loads one brand at a time.

How it works

Each brand file defines a pair of custom properties per icon: --aec-ig-<name> (the glyph) and --aec-if-<name> (the font). If a brand doesn't have an icon, it uses the DRS Base glyph. css/brand-icons.css loads the six fonts and swaps the glyph in. The fonts are only downloaded when a brand that uses them is shown.

Accessibility

  • Decorative icons next to text get aria-hidden="true".
  • An icon-only control needs an accessible name, for example aria-label="Close".
  • Meaningful icons must meet 3:1 contrast with their background (WCAG 1.4.11).
  • Icon fonts are hidden from screen readers by aria-hidden. Never put meaning only in the glyph.

Notes

  • Icon names keep the casing from IcoMoon (for example Browser and VideoCamera). This site normalises them to lowercase with hyphens, such as browser and videocamera.
  • Chevrolet and Car Bravo share the same brand tokens, but their icon fonts are different.
