Library

Search by name and click an icon to copy its name. The SVGs on this site are the 24px masters, and they scale cleanly to other sizes.

Usage

Icons are drawn with a CSS mask, so they inherit color. Set the colour with an icon token and the size with a size modifier.

<span class="aec-icon aec-icon--24" style="--aec-icon-src:url(/assets/icons/calendar-check.svg)" aria-hidden="true"></span>

/* or inline the SVG — fills use currentColor */
.my-icon { color: var(--aec-color-icon-variant); }

Accessibility

  • Decorative icons next to text get aria-hidden="true".
  • An icon-only control needs an accessible name, for example aria-label="Close".
  • Meaningful icons must meet 3:1 contrast with their background (WCAG 1.4.11).
