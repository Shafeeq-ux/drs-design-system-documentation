Patterns

About patterns

Patterns are larger components assembled from the foundation: page shells, navigation, sheets, cards and checkout screens. They come from the DR 2.0 – SC GM Chevy Components Figma library.

Status: in progresscss/patterns.css

Every pattern is built from the foundation's tokens and components. A side-sheet footer, for example, is a price block plus a button, and a finance offer card is a chip, a price table and a toggle button. Add patterns.css after components.css to use them.

Catalogue

Conventions

  • Image slots. Vehicle photos, dealer logos, lender logos and trade-in provider logos are content, not part of the system. They appear as grey .aec-img-slot placeholders.
  • Responsive. Figma draws separate Web, Tablet and Mobile variants. In code, one responsive pattern covers all of them, mostly with container queries, so a pattern adapts to the width of the column it sits in.
  • Sample copy. Demo text and prices are illustrative.
  • Figma notes. As on the component pages, each pattern ends with the inconsistencies found in the library.
