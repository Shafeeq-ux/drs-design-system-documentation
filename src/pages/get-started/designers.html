Get started

For designers

The Figma library DR 2.0 – SC GM Chevrolet Design Foundation is the source of truth. This site documents it and mirrors it in code.

Enable the library

  1. In your Figma file, open Assets → Libraries (Alt/Option + 3, then the book icon).
  2. Turn on DR 2.0 – SC GM Chevrolet Design Foundation. Its components depend on GM • 01. Core Variables and GM • 02.00 Domain Variables, so enable those too.
  3. Use the colour, text and effect styles. Don't use raw hex values, so that designs stay linked to tokens.

Open the library in Figma (opens in a new tab)

Pages marked 🚧 in Figma are still in progress and aren't documented here yet. See Component status.

Handoff

  • Every style name maps to a CSS token. text/subtle in Figma is --aec-color-text-subtle in code.
  • Component variant properties map to CSS modifiers. For example, Button style=outline becomes .aec-btn--outline.
  • Each component page has a View in Figma link to its source page.
