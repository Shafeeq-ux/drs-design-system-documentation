--- title: For developers description: How to use the DRS Chevrolet tokens and component CSS in your project. ---

Get started

For developers

The system ships as three plain CSS files and one small optional script. There is no framework and no build step.

1. Add the files

Link the font, the tokens, one or more brand files and the components, in that order. Then set data-brand on <html>, or on any element. components.js adds behaviour to tabs, accordions, modals, menus, tooltips, sliders and dismissable chips.

<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=DM+Sans:opsz,wght@9..40,400..700&display=swap">

<link rel="stylesheet" href="https://YOUR-DEPLOYMENT.vercel.app/css/tokens.css">
<link rel="stylesheet" href="https://YOUR-DEPLOYMENT.vercel.app/css/brands/chevrolet.css">
<link rel="stylesheet" href="https://YOUR-DEPLOYMENT.vercel.app/css/components.css">
<link rel="stylesheet" href="https://YOUR-DEPLOYMENT.vercel.app/css/patterns.css">
<link rel="stylesheet" href="https://YOUR-DEPLOYMENT.vercel.app/css/brand-components.css">
<script src="https://YOUR-DEPLOYMENT.vercel.app/js/components.js" defer></script>

<html lang="en" data-brand="chevrolet">

Brand ids: base, chevrolet, gmc, buick, cadillac, carbravo. For the raw token files (drop-in .drp-* classes, CSS variables or JSON), see Brand tokens.

For production, copy the files into your own repo rather than hot-linking them, and pin to a release from the changelog.

2. Use tokens

Every Figma style is a CSS custom property with the --aec- prefix. The names match Figma, so a value in a design file maps straight to code.

FigmaCSS
Colour style primary/defaultvar(--aec-color-primary-default)
Text style heading/3.aec-heading-3 or --aec-typography-heading-3-*
Effect style shadow/mvar(--aec-box-shadow-m)
Token spacing.container.padding.mvar(--aec-spacing-container-padding-m)
Token border.radius.defaultvar(--aec-border-radius-default)

The raw values are also published as JSON at tokens/chevrolet.json, for Style Dictionary or other tooling.

3. Use components

Components are BEM-style classes with the .aec- prefix. A block is modified with --modifier classes:

<button class="aec-btn aec-btn--primary">Continue</button>
<button class="aec-btn aec-btn--primary aec-btn--outline">Save for later</button>
<button class="aec-btn aec-btn--secondary aec-btn--plain">Cancel</button>

States use native attributes wherever possible (disabled, aria-pressed, aria-selected, aria-expanded, aria-invalid, :checked), so the right state is announced to assistive technology.

Working on this site

# rebuild tokens.css and every page from src/
npm run build

# local preview at http://localhost:4321
npm run dev

Change token values in tokens/chevrolet.json and page content in src/pages/, then rebuild. Don't edit the generated css/tokens.css or root-level .html files by hand.
