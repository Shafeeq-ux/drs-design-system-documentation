Foundations

Typography

One typeface and a small set of styles. Display and headings scale down on mobile, and body styles stay the same at every size.

Typeface: DM Sans11 styles · 3 breakpoints

Figma uses Chevy Sans. The web build uses DM Sans from Google Fonts. Weights are mapped as follows: Chevy Sans Medium → 400, Demi → 600, Bold → 700. body/*/medium uses 500.

Sizes are mobile-first. Desktop and tablet values apply from 768px up. The Figma tablet and desktop styles are identical.

Display

For hero headlines and marketing moments. Use at most one per screen.

Headings

Headings form the outline of the page. Keep the visual level in step with the HTML level (h1–h6).

Body

body-1 (16px) is the default for running text. Use body-2 for dense UI and body-3 for captions and legal text.

Body modifiers

The Figma body styles come in regular, medium, bold, link, all-caps and list flavours. In CSS, combine a body class with a modifier:

body-2 regular

body-2 medium

body-2 bold

body-2 link

body-2 all caps
