Foundations

Typography

A small set of styles: display, six headings and three body sizes. Each brand sets its own typeface, sizes, weights and letter case. The values below are read live from the brand chosen in the header.

Typeface: brand font11 styles · 3 breakpoints.drp-typography-*

Typography isn't a --aec- variable in the brand files. Each style is a class with a font shorthand, such as .drp-typography-heading-1 { font: 700 26px/36px "Chevy Sans"; text-transform: none; … }. Larger sizes sit inside @media (min-width: 768px) and @media (min-width: 1025px) blocks, and brands with separate mobile styles add .drp-typography-mobile-heading-*. Body styles come in variants: -regular, -medium, -bold, -link, -all-caps and -list. The --aec-font-family-* and --aec-font-weight-* variables only name the families and weights.

On this site you can use the brand file's class names directly: class="drp-typography-heading-1" re-themes with the brand. Each value is also a custom property, --drp-typography-<style>-font-size, -line-height, -font-weight, -font-family, -text-transform and so on. Components use their own type classes, such as .drp-button-contained-typography-large.

Brand typefaces are licensed, so this site shows a free substitute: Chevy Sans as DM Sans, StratumGMC as Barlow, Buick as Figtree and Lexend, and Cadillac Gothic as Archivo. See Brand fonts.

Display

For hero headlines and marketing moments. Use at most one per screen.

Headings

Headings form the outline of the page. Keep the visual level in step with the HTML level (h1–h6).

Body

body-1 (16px) is the default for running text. Use body-2 for dense UI and body-3 for captions and legal text.

Body modifiers

The Figma body styles come in regular, medium, bold, link, all-caps and list flavours. In CSS, combine a body class with a modifier:

body-2 regular

body-2 medium

body-2 bold

body-2 link

body-2 all caps

Full scale

The core styles, with values from the active brand's --drp-typography-* tokens. The .aec-* names are kept as aliases.

All brand type classes

Every .drp-typography-* class the active brand defines, including body variants (regular, medium, bold, link, all caps, list), button text and the separate mobile styles. Each class is a font shorthand in the brand file, plus text-transform, letter-spacing, text-decoration and text-indent. Select a class name to copy it.

Usage

<!-- brand type classes, the same names as the brand files -->
<h1 class="drp-typography-heading-1">Review your deal</h1>
<p class="drp-typography-body-1-regular">Your estimated payment includes taxes and fees.</p>
<a class="drp-typography-body-2-link" href="…">View payment summary</a>

/* or with the custom properties behind them */
.title {
  font: var(--drp-typography-heading-3-font-weight) var(--drp-typography-heading-3-font-size)/var(--drp-typography-heading-3-line-height) var(--drp-typography-heading-3-font-family);
  text-transform: var(--drp-typography-heading-3-text-transform);
}

On this site, .drp-typography-* classes follow the nearest [data-brand]. The older .aec-heading-*, .aec-body-* and .aec-display-* classes still work. They use the mobile styles below 768px when a brand defines them.
