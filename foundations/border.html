Border

A small set of radii and widths keeps every surface and control consistent.

Radius: 5 tokensWidth: 8 tokens

Radius

default (8px) is used for buttons, inputs and cards. rounded-rect (4px) is for small elements and focus rings. rounded makes pills and circles.

Width

default (1px) is for dividers and input outlines. 2px (border-width-20) is for outline buttons and selected states.

Focus

Focus rings use --aec-color-focus-default with --aec-border-radius-focus. Interactive components show a 2px ring, offset by 2px, when focused from the keyboard.
