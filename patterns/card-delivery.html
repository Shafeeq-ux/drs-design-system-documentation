Figma notes

  • "Schedule Delivery-" is actually a pending-documents panel ("Few things to complete…"). The code calls it .aec-todo.
  • The pickup copy differs between variants ("Pick up your vehicle…" and "Pick your vehicle…"). The appointment tile mentions "2021 RDX", which is Acura sample data.
  • There are no mobile variants. The cards stack in the responsive grid.
  • The selected border in the appointment tile is a hidden overlay. The code uses action/border/active.
