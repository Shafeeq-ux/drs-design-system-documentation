Figma notes

  • The Financing info hover state binds its border to bg/variant, which looks like a mistake. The code keeps border/default and adds a shadow.
  • The summary status text uses success/on-subtle, which isn't in the token list. It maps to success/default.
  • Lender logos (for example Bank of America) are image slots.
