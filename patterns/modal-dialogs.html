Modals & dialogs

Content built on the foundation modal for focused checkout decisions: confirming a deal, changing how add-ons are paid, sharing, reserving or switching a vehicle, signing in and contacting the dealer.

Modal · 12 content types · 5 dialogsdialog.aec-modal.aec-dialog

Figma styles these dialogs inconsistently (radius 0, 4 or 8, with or without a shadow). The code uses one treatment, .aec-dialog: an 8px radius with shadow/l on desktop, and a 16px top radius as a bottom sheet on mobile.

Accessibility

Focus and naming WCAG 2.4.3 · 4.1.2

Every dialog is a native <dialog> named by its title. Focus starts on the first field, or on the close button for confirmations.

OTP WCAG 1.3.5 · 3.3.1

Label each digit, and put autocomplete="one-time-code" on the first so SMS autofill works. Pasting a full code fills every digit. Show errors in text.

Comparisons WCAG 1.3.1

Old values use <del>, so the before → after change is clear without relying on strikethrough styling.

Figma notes

  • Dialog – Share uses heading-4 for its title. All the others use heading-5.
