Live session

When a dealer starts a Live Personal Session, a banner invites the shopper to join. During the session, a dark toolbar holds the session tools.

Live Banner · Live toolbar.aec-live-banner · .aec-live-bar

Live banner

Live Personal Session Active

Your dealer is online. Join the Live Personal Session now.

Session toolbar

Docked to the right edge on desktop (vertical) and to the bottom on mobile (horizontal). The tools are toggle buttons.

Specification

PartValue
Bannersuccess/default background, 16px padding, shadow/l, square corners. A 48px white badge with a 32px icon, a heading-5 title and body-2 text in text/inverse. Actions are an inverse link and an inverse button.
Toolbardark-grey/strong, 8px padding, 16px gap, shadow/s. 4px radius on the side facing the screen.
Tool32px, 4px radius, inverse/icon/default. Active tools use backdrop/default with a 1px inverse/border/variant ring.

Accessibility

Toolbar WCAG 4.1.2

Use role="toolbar" with an aria-label. Each tool needs an aria-label and aria-pressed for its on/off state.

Banner timing WCAG 2.2.1

The invitation stays until the shopper joins or dismisses it.

Figma notes

  • Active tools are darker, which gives low contrast. The code adds a 1px ring.
  • Tool icons are black by default in Figma. On the dark bar they need icon/inverse.
  • The tool icons and their meanings aren't named in Figma. The tools shown here are illustrative.
  • The banner shadow is a raw effect (0 4 4, 25%). The code uses shadow/l.
