Footers

Action rows that move the shopper forward: the inline footer at the end of a form, the sticky bottom navigation bar with the price summary, and a full-width mobile call to action.

Inline footer · Bottom Navigation Bar · Mobile bottom button.aec-form-footer · .aec-bottom-bar

Inline footer

Sits at the end of the page content, below a 1px divider. On desktop, Back is on the left and Continue on the right. On mobile, the buttons stack full width with the primary action first.

With consent

Bottom navigation bar

Sticks to the bottom of the content column. On desktop it holds the next-step button. Below 1280px, where the Mathbox rail is hidden, it also shows the vehicle and price. It can include a Skip action and the segmented progress bar.

Accessibility

Sticky content WCAG 2.4.11

Make sure the sticky bar never hides focused elements. The page template adds bottom padding equal to the bar's height.

Button order WCAG 1.3.2 · 2.4.3

On desktop, keep Back before Continue in the DOM, and use CSS for the mobile reordering. This keeps the focus order logical.

Figma notes
