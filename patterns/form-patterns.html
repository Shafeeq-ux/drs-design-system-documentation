Accessibility

Questions are fieldsets WCAG 1.3.1 · 3.3.2

Wrap each question in <fieldset> with the question as its <legend>, so every option is announced with its question.

Sensitive data WCAG 1.3.5

Mask Social Security numbers, use autocomplete on personal fields, and explain why the data is needed.

Figma notes

  • The option copy is placeholder ("Tab Label", "Enter text").
  • The Basic form sample shows an unmasked SSN and a typo ("Freenam"). The code masks the field.
  • The tiles use raw hex (#ffffff, #e6e6e6). The code uses bg/default and border/default.
