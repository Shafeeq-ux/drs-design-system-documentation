Notifications

Status messages in four styles: a floating toast, a solid banner, an inline tinted notice and a slim one-line alert. Each comes in five kinds.

4 Figma sets · 5 kinds.aec-notice

These extend the foundation alert, banner and snackbar with status colours and a 24px status icon, and add the secondary kind (grey). Pick the style by how prominent the message should be.

Toast

A white floating card with a 2px left accent, a coloured title and an optional "Learn more" link. Use it for transient results. It's the status-aware replacement for the snackbar.

Accessibility

Live regions WCAG 4.1.3

Toasts render in an aria-live="polite" region. Errors that block progress use role="alert".

Contrast WCAG 1.4.3

White text on warning/default is only 3.4:1, so the solid warning banner uses warning/on-default (#1a1a1a, 5.18:1). Toast and inline warning titles use a darker text colour (#7a5a1e).

Timing WCAG 2.2.1

Toasts stay for 8 seconds, pause while hovered or focused, and always have a close button.

Figma notes

  • The Banner notification's warning kind uses white text on #b3842d, which fails AA. The code switches it to dark text.
  • The In-page Alert Banner's Information status uses a saturated blue background (#007cc0, bound to decoration/02) with a blue icon. The code uses info/subtle and info/default, like the other statuses.
  • The radius varies: banner and toast 8px, inline 0, slim alert 4px.
  • The shadows are raw effects. The toast shadow (0 30 60, 15%) isn't a token.
  • Negative reuses the Warning glyph. The code uses warning.svg for both, and state-error.svg for slim errors.
