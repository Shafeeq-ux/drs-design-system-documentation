Accessibility

Landmark and current step WCAG 1.3.1 · 4.1.2

Use <nav aria-label="Checkout steps"> and mark the current item with aria-current="page". Status icons need a text alternative, such as "Completed".

Unavailable steps

Locked steps use aria-disabled="true" without an href, and the status icon explains why ("Complete earlier steps first").

Rail labels WCAG 2.4.4

Icon-only rail items need an aria-label. Add a tooltip on hover for sighted users.

Drawer WCAG 2.4.3

The mobile drawer is a <dialog>, so focus is trapped while it's open and returns to the menu button when it closes.

Figma notes

  • The nav component is 216px wide but its items are 238px. The templates use both widths.
  • Hover looks the same as default. The code adds a bg/variant hover.
  • The disabled-item info icon has no tooltip in the spec.
  • "Card - Nav" items are an older style and aren't used by this nav.
