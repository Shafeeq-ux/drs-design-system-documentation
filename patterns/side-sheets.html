Accessibility

Dialog WCAG 2.4.3 · 4.1.2

Sheets are a native <dialog> opened with showModal(), so focus is trapped, Esc closes the sheet and focus returns to the trigger. Name the dialog with aria-labelledby.

Navigation rail WCAG 2.1.1

The rail is a vertical tab list. ↑ and ↓ move between items and each item controls a content panel.

Add / Added WCAG 4.1.2

The footer toggle uses aria-pressed. Announce the price change in a polite live region.

Conflict panel

Use role="alertdialog" and move focus to it, because the shopper must decide before continuing.

Figma notes

  • The header master uses heading-3, but every instance overrides it to heading-5. The code uses heading-5.
  • The conflict scrim (#0f0f0f at 40%) has no token.
  • Payment options is built on a hidden base named "… old". Its Summary types exist only on mobile.
  • Doc preview has an "Acura" axis, a leftover brand name for the image-viewer mode.
  • Bottom sheets and mobile payment options use the Web footer variant (16/24 padding).
